# Claude-Philanthropy-Skill-Library

Great ideas need a home. The goal of this repo is to collect and share a trustworthy source for Claude Skills that are relevant and beneficial for Foundations and other Philanthropic and Grantmaking organizations. Collaborators include Chantal (Coco) Forster and many colleagues from TAGtech.org
